# Academic Advisor Demo

A small BSc Computer Science, Year 2 academic-advising demonstration. It combines a scikit-learn performance-risk model with a Flask web app and practical support suggestions.

## Important limitation

The training dataset and its labels are synthetic and generated by a simple rule. The reported metrics only describe how well the model recovers patterns from that synthetic generator; they do not establish accuracy for real students. Do not use this model for real academic decisions. Replace the synthetic data with approved, consented, appropriately anonymized data and get institutional review before making any real-world claims.

## Project files

- `app.py`: Flask web application; validates form inputs, loads the serialized model, and displays an estimate and support suggestions.
- `train_model.py`: reproducibly creates synthetic data, trains and evaluates the pipeline, and saves the CSV and `.pkl` artifact.
- `models/performance_risk_model.pkl`: model bundle consumed by the web app.
- `data/synthetic_student_performance.csv`: generated demonstration data.
- `tests/test_app.py`: route, validation, and health-endpoint tests.

## Run locally on Windows

From the project folder in PowerShell:

```powershell
uv venv --python 3.13 .venv
uv pip install --python .\.venv\Scripts\python.exe -r requirements.txt
uv run --python .\.venv\Scripts\python.exe train_model.py
uv run --python .\.venv\Scripts\python.exe -m pytest -q
uv run --python .\.venv\Scripts\python.exe app.py
```

Open `http://127.0.0.1:5000`. The virtual environment is local and should not be committed. `requirements.txt` records the direct dependencies.

## Train the model in Google Colab

The training script is Colab-compatible, but each student must run it in their own Colab session for the assignment's Colab requirement:

1. Create a new notebook at [Google Colab](https://colab.research.google.com/).
2. Upload `train_model.py` into the Colab session.
3. Run this cell to install its dependencies:

	```python
	%pip install numpy pandas scikit-learn joblib
	```

4. Run the training script:

	```python
	%run train_model.py
	```

5. Download the generated model artifact:

	```python
	from google.colab import files

	files.download("models/performance_risk_model.pkl")
	```

6. Replace the local file at `models/performance_risk_model.pkl` with the downloaded artifact, then rerun the tests and web app.

Keep the notebook and its output in your Google Drive or export it into this repository as evidence that you trained the model in Colab. Do not present the synthetic metrics as real-world validation.
